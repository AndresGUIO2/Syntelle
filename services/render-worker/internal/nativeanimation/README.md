# Native animation state

`LoadBundle(motionJSON, gazeJSON, expressionJSON, oralJSON)` reads the existing prepared JSON and binds the original oral seed. `NewEngine(config)` owns a session's seeded attention, blinking and expression history; call it sequentially, without concurrent access.

`Engine.Sample(animationMS, SpeechState, Settings)` returns head angles in degrees, breathing displacement in source pixels, the renderer-safe mouth pair/amount, lid closure, source-pixel gaze offsets, and smile/brow weights. Supply a monotonic pause-aware animation clock. `SpeechState.Position` is seconds on the emitted PCM sample clock, not request arrival or wall-clock synthesis time. Preserve the same `Speech` pointer through a phrase and its natural completion/release; clear it and advance `Session` on interruption. `Settings.Paused` returns the preceding frame. The caller removes paused time from `animationMS` when resuming.

Defaults match the private Syntelle catalog: directed performance, conversational attention, 30-target streaming, automatically blinking/moving, and registered closed smiles. `DefaultSettings()` enables movement, blinking and automatic expressions. Rendering, media, providers and I/O are not dependencies of this package.

The native media preparation lane decodes a PCM WAV once, builds transient samples as `float32(pcm16)/32768`, then calls cancelable `PrepareSpeech` before audio can consume the clip. Its immutable `PreparedSpeech` retains only timeline/cues/gestures, without PCM. Preparation may parse optional performance but never admits it or changes an engine. On the first active video frame, the scene owner calls `Engine.AdmitPerformance` with the existing media-clock timestamp and `BindSpeech` with that result. Binding shares the prepared analysis without changing it; admission preserves cue anchors, existing head/smile bounds and smile cooldowns, and rejects unavailable laughter. `SpeechSeed(text)` preserves the original character/text seed. The synchronous `BuildSpeech`/`BuildSpeechWithPerformance` wrappers remain for original reference fixtures. No new speech/provider request is made by this package.

`services/render-worker/scripts/export-animation-fixtures.mjs` executes the original TypeScript directors, speech planner and viseme mapping using cached PCM and controlled clocks. Its deterministic JSON contains 3,281 frames covering quiet/speaking attention, gaze, seeded spontaneous/double blinks, breathing, directed gestures, expressions, settings, reduced motion and pause/resume. Go tests compare those reference values and the actual acoustic plans; no Go-generated expected values are used. The 90-second idle duration is simulated time, not a long-running browser benchmark. Linux live-render/media checks remain separate.
