## Adaptation

The subsequent owner-supplied conversation HTML guides the [conversation workspace refresh](../development/conversation-workspace.md). Its original source is preserved in the private phase-32 evidence. Apply its conversation-first hierarchy to the actual three-character experience, with Syntelle's existing palette and real service states.

Keep the prominent portrait, focused adjacent workspace, compact branding, graphite and soft violet themes, and separate supporting flows. Adapt the layout responsively instead of copying fixed-size presentation frames. Keep only the current status visible. Keep owner administration separate from public controls and avoid decorative usage meters or duplicate calls to action.

The first local build keeps the desktop mockups' 64 px header, 1440 px workspace, 1:1.15 portrait/workspace proportions, and two equally tall panels. Validated images appear in the left stage without cropping. The upload and validation flow occupies the right panel; its bottom composer is visibly disabled and explicitly marked unavailable. Do not fabricate transcripts, usage counters, saved-character claims, or active speech controls before those features exist. Mobile uses a single column with natural page scrolling.

Keep the Colors Studio logo transparent against the header. Use the original white-lettered SVG wordmark on dark desktop headers, only the supplied multicolor symbol on light desktop headers, and the symbol on mobile in either theme. Do not add a separate company-name text label beside the symbol. Keep it distinct from the Syntelle product wordmark. The header upload button opens the same working file picker as the upload panel.

## Character direction

The generated photorealistic human in the supplied mockups is rejected. The desired sample is an original semi-realistic illustrated digital character, similar in visual treatment to the earlier [protected reference](../product/character-reference.md): a frontal head-and-shoulders portrait, softly rendered facial surfaces, slightly stylized proportions, a clear neutral expression, professional styling, and a clean background.

Use the reference for broad style and framing, not the same identity, costume, images, or overlays. An owned or authorized sample must be supplied or generated when facial processing begins. Do not fetch or reuse the rejected portrait URLs from the HTML in application assets.

This sample-art direction does not bypass compatibility validation for visitor uploads or authorize reuse of the protected example.
